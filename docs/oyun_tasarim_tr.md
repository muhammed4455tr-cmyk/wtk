# Oyun Tasarım Özeti (Türkçe)

## Konsept
- Tür: Korku + aksiyon + kaçış
- Mekan: Gece ofisi
- Hedef: Araba anahtarını bul, düşmanları atlatarak/öldürerek otoparka ulaş, arabayı çalıştır ve kaç.

## İstenen temel özellikler
- Silahlı çatışma
- Düşman AI devriye/takip
- Anahtar bulma görevi
- Debriyaj + kontak tabanlı araç çalıştırma mini-game
- Türkçe diyalog ve HUD
- Çevrim içi oynanış (arkadaşla)

## MVP kapsamı (bu repo)
- Tek oyuncu oynanabilir prototip
- Basit düşman kovalamaca + mermi sistemi
- Anahtar toplama, araba etkileşimi, devir göstergesi benzeri başlatma sekansı
- Temel online hareket senkron demo

## Tam sürüm için önerilen teknoloji
- Oyun motoru: Unreal Engine 5 veya Godot 4
- Ağ: Dedicated server (ENet/Steam Networking/Photon)
- Ses: FMOD/Wwise + binaural korku miksleri
- Araç: Fiat Egea benzeri lisanslı/izinli model ve fizik ayarı
