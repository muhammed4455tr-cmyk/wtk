# Karanlık Koridor (Mini Korku Oyunu)

Tarayıcıda çalışan, metin tabanlı mini bir korku oyunu.

## Çalıştırma

Bu klasörde bir HTTP sunucusu başlatın:

```bash
python3 -m http.server 4173
```

Ardından şu adrese gidin:

- http://localhost:4173

## Oynanış

- Farklı odalar arasında seçim yaparsınız.
- Yanlış seçimler can azaltır.
- `Fener` öğesini kullanarak iyi sona ulaşabilirsiniz.
